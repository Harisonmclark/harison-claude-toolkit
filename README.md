# Harison's Claude toolkit

Personal shortcut commands for Claude.

| Command | What it does |
| --- | --- |
| `/harison:today` | Shifts, interviews, deadlines and agent runs for the day |
| `/harison:apply <job link>` | Starts a full application package |
| `/harison:prep <interview details>` | Interview research, likely questions, stories, thank-you note |
| `/harison:followup <contact>` | Ready-to-send follow-up checked against past emails |

## Install in the Claude app (Cowork)

1. Open **Customize** in the sidebar, then **Plugins**.
2. Choose **Add marketplace** and enter this repository (`Harisonmclark/harison-claude-toolkit`).
3. Find **harison** in the list and choose **Install**.

## Install in Claude Code

```
/plugin install harison --marketplace Harisonmclark/harison-claude-toolkit
```
